一台你自己的 VPS

在服务商后台找到公网 IPv4 地址，确认使用 Ubuntu 或 Debian 系统。

什么是 VPS？我还没买怎么办？

可以把 VPS 理解为租来的远程电脑。工具会在这台电脑上运行代理服务。如果还没购买，请先选择服务商、了解续费和流量规则，购买后再回到这里。VPS 费用由服务商收取，本工具不提供服务器。

你来准备

服务器的 root 登录密码

这是服务商提供的服务器管理密码。它用于登录 VPS，不是服务商网站的账号密码。

在哪里找到密码？

通常可以在服务商的实例详情、开通邮件或控制台中找到。当前版本只支持 root + 密码登录。如果服务商只提供 SSH 私钥，需要先按其官方说明配置登录方式；不要把私钥粘贴到密码框。

检测到的 SSH 主机指纹

第一次使用，怎么核对指纹？

打开服务商提供的网页 Console / VNC 终端，登录服务器，运行下面的只读命令。将输出的任一 SHA256 指纹与上方对比，确认完全相同。

for file in /etc/ssh/ssh_host_*_key.pub; do ssh-keygen -lf "$file"; done

如果无法核对，先查看服务商的 SSH 连接说明。主机指纹突然变化时，请确认是否重装过系统，或联系服务商。

端口是什么？为什么还要去服务商后台放行？＋
可以把端口理解为服务器上不同服务的“门牌号”。SSH 登录默认使用 22，节点默认使用 18443，两者用途不同。
如果服务商启用了云防火墙或安全组，需允许设备访问节点端口的 TCP 和 UDP。如果服务器内部也启用了防火墙，还需要相应放行。工具不会替你关闭防火墙或修改规则；不确定时先看服务商官方说明。

      
我只有 IP，没有密码，可以直接搭建吗？＋
还不能。IP 只表示服务器的位置，登录还需要证明你有管理权限。当前版本使用 root 密码连接；请先从服务商后台或开通邮件获取正确的登录信息。
如果服务器只允许密钥登录，本版本暂不支持，不能把私钥当成密码填入。

      
提示 SSH 连接失败，应该先检查什么？＋
依次核对：公网 IP 是否正确、服务器是否开机、SSH 端口是否与服务商提供的一致、root 密码是否复制完整。如果浏览器登录过服务商网站，也不代表已经登录到 VPS。
遇到超时，先检查 SSH 端口能否访问；遇到认证失败，先确认账号和密码。不要连续反复尝试或直接重装系统。

      
显示“部署成功”，但网页还是打不开？＋
先看结果页是否通过“出口 IP”和网页连接验证；再确认节点端口已放行，Clash Verge 中已选中新节点并开启系统代理。手机上则需要开启客户端连接。
某些应用不使用系统代理，可能需要应用自身的代理设置。网站自身的账号、年龄或地区限制，也不会因为节点部署成功就自动解除。

      
会覆盖我已有的节点或影响其他服务吗？＋
服务端使用独立目录和服务名；发现端口被占用会停止。自动导入 Clash Verge 时会保留旧订阅，先备份设置，再新增一个本地配置。
不过 root 操作仍需谨慎。正在运行重要业务的 VPS，建议先做快照并了解已有服务，不要并行运行多个安装脚本。

      
失败后怎么办？旧配置还能恢复吗？＋
服务端配置检查或启动失败时，工具会尝试恢复原配置和运行状态。若服务端已成功、只是客户端连接失败，服务器上的节点会保留，不会直接删除。
Clash Verge 原配置备份在本机 runtime/backups 目录。可以先在客户端切回旧订阅，再根据结果页的备份信息排查。断电、SSH 中断等情况不能保证完整自动恢复。

      
关闭电脑或这个页面后，节点会停止吗？＋
部署完成的代理服务运行在 VPS 上，关闭电脑不会让服务器上的节点停止；手机可以独立连接。VPS 关机、欠费或服务异常则会影响连接。
部署过程中请保持本机工具运行。刷新页面会尝试恢复当前会话的任务展示，但关闭本地服务或重启电脑后，需要重新检查服务器状态。
